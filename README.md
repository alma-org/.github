# alma-org/.github

Organization-wide defaults for [alma-org](https://github.com/alma-org).

The organization profile — what visitors see at <https://github.com/alma-org> — is rendered from
[`profile/README.md`](profile/README.md). GitHub only reads that path; this file is the README of the
repository itself and never appears on the profile page.

Anything else placed here (issue and pull request templates, `CONTRIBUTING.md`, `SECURITY.md`) applies to
every repository in the organization that does not define its own.
